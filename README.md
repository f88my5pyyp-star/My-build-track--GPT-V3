# My Build Track v4

A responsive project/build tracker designed for iPhone, tablet and desktop.

### Included
- Dashboard with six-tab navigation
- Project creation/edit/delete and status
- Budget, revenue and profit tracking
- Activity-based progress tracking
- Expense categories, units, purchase links and receipt photos
- Project-specific reports
- PDF generation and sharing
- AUD/USD/INR currency
- JSON export/import and manual save
- PWA/iPhone Home Screen logo configuration

### Vercel
Upload the contents of this folder to the root of the existing GitHub repository:
`index.html`, `manifest.webmanifest`, and the entire `assets` folder.
Vercel will redeploy automatically.

This release is a browser-local app. Data is stored in localStorage; use Export All Data for backup.
